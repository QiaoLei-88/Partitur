# Delegate

A short-lived agent started by another session for a bounded task. It
writes nothing; the session that started it says so and verifies what it
relies on: claims passed on unchecked are how a delegate's mistake becomes
a project's. Two kinds:

## Mechanical delegate (B6)

A read-only, bounded, mechanical task, such as sweeping source for every
use of an array, may go to a smaller, cheaper model without a separate
authorization. It gets a written scope, restrictions, deliverable, and
acceptance criteria. Its findings are checked before they enter a record.

## Independent reviewer (B11)

Where no integrator reviews the work (for example, a repository with one
writer), a fresh agent reviews each milestone. It is given the records only,
not the author's reasoning, so that it can disagree; its task is judgment,
not mechanics, so it is not limited to a cheaper model. The author records
the findings and their resolution.
